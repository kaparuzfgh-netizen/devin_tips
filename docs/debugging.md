# Отладка — протокол разбора ошибок

Применяй, когда что-то не работает, пришла ошибка API или проверка не прошла.
Короткая версия и стоп-правило есть в `../AGENTS.md`; здесь — полный протокол.

1. **Воспроизведи.** Какая команда/действие, что ожидалось, что получено.
2. **Зафиксируй точный ответ.** Для Bot API: `code`, `description`, `parameters` и объект
   параметров, который отправили (без токенов). Если логов не хватает — сначала добавь
   логирование, потом чини.
3. **Одна гипотеза → одна проверка.** Назови гипотезу, назови проверку, которая её подтвердит
   или опровергнет, выполни. Не меняй несколько вещей сразу. Не выдавай догадку за причину.
4. **Минимальное исправление.** Не рефакторить попутно, не удалять логи и обработку ошибок.
5. **Запиши в `KNOWN_ISSUES.md`:** симптом, точный текст ошибки, гипотезы со статусом
   (подтверждена / опровергнута / не проверена), что сделано, итог.
6. **Перепроверь тем же способом**, которым воспроизводил. Только тогда статус VERIFIED.
7. **Стоп-правило.** Две неудачи подряд на одной гипотезе — остановись, опиши владельцу
   ситуацию и предложи один вариант по умолчанию.
