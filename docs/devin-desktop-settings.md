# Настройки Devin Desktop для вайбкодинга

Режим, когда агент пишет код, а владелец управляет задачами и проверяет результат
по `npm run check`, а не читает каждый diff. Настройки ниже убирают визуальный шум.
Они меняют только интерфейс редактора и не влияют на код, сборку и тесты.

## Где лежат
`.vscode/settings.json` в корне проекта. Файл хранится в git (в `.gitignore` для него
сделано исключение), остальное содержимое `.vscode/` игнорируется. Блок ниже — копия для справки.

```json
{
  "workbench.editor.showTabs": "none",
  "workbench.editor.enablePreview": false,
  "workbench.editor.closeEmptyGroups": true,
  "editor.minimap.enabled": false,
  "explorer.autoReveal": false,
  "files.autoSave": "afterDelay",
  "files.autoSaveDelay": 2000
}
```

## Параметры

| Параметр | Значение | Что делает | Оценка |
|---|---|---|---|
| `workbench.editor.showTabs` | `none` | Прячет панель вкладок. Файлы не копятся десятками. | Безопасно. Переключаться между файлами — через `Ctrl+P` или `Ctrl+Tab`. |
| `workbench.editor.enablePreview` | `false` | Файл из проводника открывается как обычный, а не как «предпросмотр» (курсив), который заменяется следующим. | Безопасно. Вместе с отключёнными вкладками открытых файлов станет больше: закрывай `Ctrl+W`. |
| `workbench.editor.closeEmptyGroups` | `true` | Закрывает пустые группы редактора после закрытия последнего файла. | Безопасно, это и так значение по умолчанию; фиксируем явно. |
| `editor.minimap.enabled` | `false` | Убирает миникарту справа. | Безопасно, чисто визуально. |
| `explorer.autoReveal` | `false` | Проводник не прыгает к открытому файлу. | Безопасно. Минус: текущий файл в дереве сам не подсвечивается. |
| `files.autoSave` | `afterDelay` | Сохраняет файлы автоматически. | Безопасно, с оговорками ниже. |
| `files.autoSaveDelay` | `2000` | Задержка автосохранения, мс. | Безопасно. 2 с реже будят watch-режимы (`vitest --watch`, линтер) и не пишут файл на полуслове; агент всё равно видит свежую версию. Для более быстрой синхронизации можно снизить до 1000. |

## Оговорки по автосохранению
- Файл сохраняется на полуфразе: линтер или `vitest --watch` могут на миг показать ошибку.
  Это не повод паниковать; смотри итог `npm run check`.
- Откат ручных правок: используй Git (`git restore`), а не «закрыть без сохранения».
- Секреты в файл вручную не вставляй: автосохранение запишет их на диск сразу.

## Рекомендации для вайбкодинга
- **Diff не читаем постоянно.** Критерий готовности — зелёный `npm run check` и отчёт агента
  (что изменено, чем проверено). Diff открывай выборочно: для Frozen/Core модулей
  (`SYSTEM_MAP.md`), деплоя, схемы БД и всего, что касается секретов.
- **Файлы без вкладок.** Нужен файл — `Ctrl+P` и имя. Не держи открытыми то, что не правишь.
- **Источник истины — репозиторий.** Состояние смотри в `TASK_TRACKER.md` и `git log`,
  а не в памяти чата.
- **Мелкие шаги.** Одна задача — один коммит; проще откатить, чем разбирать большой diff.
- **Перед деплоем** diff стоит просмотреть: `git diff --stat`, затем выборочно файлы.
- **Не отключай проверки** ради скорости: pre-commit хук — твоя страховка, раз код не читаешь.
- **Вернуть вкладки**: поставь `"workbench.editor.showTabs": "multiple"` или удали строку.
