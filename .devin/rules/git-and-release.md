# Git и релизы

- Ветка на задачу: `feat/<коротко>` или `fix/<коротко>`. В `master` попадает только то, что VERIFIED.
- Один коммит — одно логическое изменение. Сообщение: `тип: что сделано (T-ID)`,
  например `fix: сохранение chat_id канала (T2)`.
- Не коммить `.tgcloud/`, токены, дампы БД.

## Порядок выкладки
1. `npx eslint tgcloud` — без ошибок.
2. `npx tgcloud status` — убедись, что уходит только задуманное.
3. `npx tgcloud push`; если менялась `schema.js` — `npx tgcloud migrate`.
4. Проверь в реальном Telegram по критерию приёмки задачи.
5. Обнови статус и доказательство в `TASK_TRACKER.md` (в том же коммите).
6. Поставь тег `ok-ГГГГ-ММ-ДД-N` на проверенную версию.

## Откат
Вернуться на последний тег `ok-*`, затем `push` (и `migrate`, если схема различалась).
Откат записать в `docs/KNOWN_ISSUES.md`.
