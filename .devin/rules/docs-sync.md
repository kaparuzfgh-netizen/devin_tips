# Документация

- Документов три: `README.md`, `AGENTS.md`, `TASK_TRACKER.md`. Не создавай новых без просьбы владельца.
  Архитектура описана одним разделом в README, а не отдельным файлом.
- У каждой задачи в трекере есть **критерий приёмки** (что нажать и что должно произойти) и
  **доказательство** (команда + ответ, скриншот, ссылка на запуск Action).
- Статус меняется только по доказательству. Не знаешь — оставь WRITTEN.
- README описывает только то, что работает сейчас. Запланированное помечай как «план» и не
  выдавай за готовое.
- Менял поведение функции — обнови README и трекер в том же коммите.
- Не пиши в документы секреты и реальные значения токенов.
